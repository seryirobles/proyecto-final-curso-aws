# Design prototype — read-only reference material

**Nothing in this directory ships. Nothing in this directory is source.**

Both files were generated by Claude design (the "dc" / design-component format)
and supplied by the owner on 2026-08-16 as a visual and behavioural reference for
the SPA.

| File | What it is |
|---|---|
| `Sobremesa.dc.html` | The whole product in one file: a template in a custom DSL (`<x-dc>`, `<sc-if>`, `<sc-for>`, `{{ }}`) plus an embedded script carrying seeded mock state and handlers |
| `support.js` | A **generated build artifact**. Its first line reads *"GENERATED from `dc-runtime/src/*.ts` — do not edit."* It boots React and Babel from the unpkg CDN at runtime |

## Rules

- **Do not edit either file.** `support.js` cannot be regenerated here: its build
  step (`cd dc-runtime && bun run build`) refers to a repository that is not this
  one, and there is no `bun` in this toolchain.
- **Do not lint, type-check, format or test these files.** They are outside every
  toolchain root by design. If a tool reaches them, exclude the tool — do not
  change the files.
- **Do not port this code into `frontend/`.** It has no components, no modules,
  no build step and no tests, and it is somebody else's compiled runtime.

## Before you use it

Read **`docs/frontend_prototype.md`** first — always, and never this directory
on its own. It is the analysis of record, and its **§4 lists eleven places where
the prototype contradicts the frozen requirements**, including the shopping-list
re-sync rule settled by `G-77`. Copying a behaviour from here without checking
§4 will reintroduce a defect that was already decided out.

## What it does not decide

That the prototype runtime renders via React is an implementation detail **of the
prototype tool**. It does not close architecture **P7** (framework identity,
bootstrap idiom, test runner), which stays pending and human-owned. Feature 20
`frontend_spa` stays `blocked`.

The React-based stack itself was decided independently by the owner in
`docs/architecture.md` §1.1, before this prototype existed. There are no declared
dependencies in this repository: the CDN URLs in `support.js` belong to the
prototype's own boot sequence.
